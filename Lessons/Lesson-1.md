we work with comands today
pwd - определить в какой директории нахожусь
ls -la - вывести файлы, находящиеся в указанной директории
cd - перейти в директорию
touch - создать файл
mkdir - создать директорию
cp - копировать
mv - переместить
rm - удалить (rmdir - удалить директорию)
cat - отобразть содержимое файла
echo = вывести текст
>    = направить вывод в файл с перезаписью
>>   = направить вывод в файл с добавлением
| - передать вывод одной команды на вход другой
&& - выполнить команду, если предыдущая была успешна
|| - выполнить команду, если предыдущая была не успешна
env    — показать переменные окружения
which  — показать путь к исполняемой команде
ps     — показать процессы
top    — мониторить процессы и загрузку системы в реальном времени
kill   — отправить сигнал процессу / завершить процесс
chmod  — изменить права доступа к файлу или папке
sudo   — выполнить команду с повышенными правами
find   — найти файлы и папки
grep   — найти текст по шаблону
tar    — упаковать/распаковать файлы и папки в архив
gzip   — сжать/распаковать файл
